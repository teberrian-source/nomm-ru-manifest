# AGENTS.md — nomm-ru-manifest

## Назначение
Проект хранит русскоязычный манифест для Nuclear Option Mod Manager (NOMM): применяет переводы описаний к официальному реестру NOMNOM и выпускает `dist/` для размещения на GitHub.

## Правила
- Общение и этот файл — на русском языке.
- Всегда показывать план перед работой.
- Коммиты и ветки — строго на английском языке.
- Код чистый и простой; каждая функция — с описанием.

## Как это устроено
- `manifest.upstream.json` — снимок официального манифеста NOMNOM (https://kopterbuzz.github.io/NOMNOM/manifest/manifest.json).
- `translations.ru.json` — JSON: ключ = id мода, значение = русское описание. Поле `_comment` — служебное, не является id.
- `build.ps1` — PowerShell 5.1-скрипт сборки. Читает снимок, подставляет переводы, проверяет уникальность id и целостность, выпускает `dist/manifest.json` (UTF-8 без BOM) и `dist/version.json` (JSON-строка версии).

## Важные нюансы
- **PowerShell и кодировки**: `.ps1` с кириллицей обязателен в UTF-8 **с BOM** — иначе PS 5.1 читает файл как ANSI и парсер падает. Новые скрипты сохранять с BOM.
- **ConvertTo-Json и массивы**: PS 5.1 превращает одиночные элементы в скаляр. Перед выпуском `build.ps1` сравнивает `authors/tags/artifacts/urls` со снимком и падает, если массив сломан.
- **version.json**: строка вида "1.1.0.3004.1" (последняя часть ".1" — суффикс нашего перевода). NOMM сравнивает версии через `Version.fromString` (все нецифры отрезаются), поэтому при каждом изменении `dist/` нужно поднимать версию, иначе менеджер не перечитает манифест.
- **Консоль PowerShell показывает кракозябры** для кириллицы (кодировка вывода) — это не повреждение файла. Проверять содержимое через `[System.IO.File]::ReadAllText(путь, UTF8)`.
- **`.NET`-методы не видят `cd`** — пути к файлам давать абсолютными.

## Обновление с upstream
1. Скачать свежий manifest.json → заменить `manifest.upstream.json`.
2. Дополнить `translations.ru.json` новыми id (приоритет — топ-50 по downloadCount).
3. `powershell -ExecutionPolicy Bypass -File build.ps1 -Version <новая>`
4. Коммитить `dist/` тоже — он является артефактом, который публикуется в raw.
